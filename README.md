# NLP-tech: учебные материалы по NLP

Интерактивные страницы и блокноты для двухдневного семинара по обработке естественного языка для студентов технических специальностей. Сквозные примеры — теория вероятностей и математическая статистика.

## Интерактивные HTML-страницы

- **[Главная: программа двух дней](https://avladova.github.io/NLP-tech/)**
- **[День 1 — токенизация, BoW, TF–IDF, косинусная близость и поиск](https://avladova.github.io/NLP-tech/day1.html)**
- **[День 2 — контекст, retrieval, граф понятий, онтология и QA](https://avladova.github.io/NLP-tech/day2.html)**

Исходные файлы: [index.html](index.html), [day1.html](day1.html), [day2.html](day2.html). Страницы работают без установки библиотек. Если GitHub Pages ещё не включён: откройте **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Блокноты

- [День 1 — от текста к вектору](notebooks/day1_nlp_basics.ipynb): техническая предобработка и токенизация; частоты и n-граммы; BoW и TF–IDF; косинусная близость и поиск похожих задач.
- [День 2 — контекст, семантика, графы и генерация QA](notebooks/day2_text_vectors_and_models.ipynb): разбиение учебного текста на контекстные фрагменты и retrieval; эмбеддинги и метрики близости; граф понятий/фрагмент онтологии; генерация вопросов и ответов и проверка качества.

## Запуск блокнотов

Для основных блоков:

```bash
python -m pip install scikit-learn matplotlib networkx
```

Дополнительный эксперимент с готовой многоязычной моделью эмбеддингов требует установки библиотеки `sentence-transformers` и загрузки модели.

## Что показывают HTML-демонстрации

HTML-страницы — наглядные учебные модели, а не запуск языковой модели. Поиск на страницах основан на лексических признаках; иллюстративные оценки не следует интерпретировать как результаты реального ML-эксперимента. В блокнотах можно реализовать и сравнить алгоритмы на данных.
