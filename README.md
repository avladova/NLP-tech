# NLP-tech: учебные материалы по NLP

Два учебных дня для студентов технических специальностей. Сквозной пример — тексты и задачи по теории вероятностей и математической статистике.

## Блокноты

- [День 1 — от текста к вектору](notebooks/day1_nlp_basics.ipynb): четыре пары — техническая предобработка и токенизация; частоты и n-граммы; BoW и TF–IDF; косинусная близость и поиск похожих задач.
- [День 2 — контекст, семантика, графы и генерация QA](notebooks/day2_text_vectors_and_models.ipynb): четыре пары — разбиение учебного текста на контекстные фрагменты и retrieval; эмбеддинги и метрики близости; граф понятий/фрагмент онтологии; генерация вопросов и ответов и проверка качества.

## Запуск

Для основных блоков:

```bash
python -m pip install scikit-learn matplotlib networkx
```

Дополнительный эксперимент с готовой многоязычной моделью эмбеддингов:

```bash
python -m pip install sentence-transformers
```

Для загрузки модели нужен доступ к интернету. Этот блок можно пропустить, если среда семинара не имеет сетевого доступа.

## Методические ограничения

Каждый день рассчитан на четыре пары (ориентировочно 4 × 90 минут). В первом дне строится лексический поисковый базис. Во втором добавляются контекстные фрагменты, retrieval, эмбеддинги, граф понятий и конвейер QA. Демонстрационный граф частично задан вручную, а QA-примеры шаблонные: извлечение знаний из произвольной книги и полноценная генерация языковой моделью являются отдельными задачами. Косинусная близость — сигнал сходства, а не доказательство фактической корректности ответа.
