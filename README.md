# NLP-tech: учебные материалы по NLP

Репозиторий содержит практические блокноты для двух учебных дней. Примеры ориентированы на базовые задачи обработки русскоязычных текстов и включают финансовую тематику.

## Материалы

- [День 1 — основы NLP](notebooks/day1_nlp_basics.ipynb): предобработка, токенизация, частотный анализ, Bag of Words, TF–IDF.
- [День 2 — векторизация и модели](notebooks/day2_text_vectors_and_models.ipynb): TF–IDF, косинусное сходство, классификация, концепция эмбеддингов и задания.

## Запуск

Откройте блокноты в Jupyter Notebook/JupyterLab или загрузите их в Google Colab. Для выполнения основных ячеек достаточно Python 3. Для TF–IDF и классификации требуется `scikit-learn`:

```bash
python -m pip install scikit-learn
```

Блокноты содержат учебные данные. Результаты на небольших искусственных корпусах нельзя интерпретировать как оценку качества промышленной NLP-системы.
