# NLP-tech: учебные материалы по NLP

Репозиторий содержит материалы для двух учебных дней по обработке естественного языка. Целевая аудитория — студенты технических специальностей. Практические корпуса построены на формулировках задач по теории вероятностей и математической статистике.

## Практические блокноты

- [День 1 — от технического текста к числовым признакам](notebooks/day1_nlp_basics.ipynb): четыре пары — очистка и нормализация; токенизация и n-граммы; статистика корпуса и частоты; Bag of Words и TF–IDF.
- [День 2 — поиск, классификация и оценка NLP-моделей](notebooks/day2_text_vectors_and_models.ipynb): четыре пары — поиск похожих задач и косинусное сходство; семантические эмбеддинги; классификация; метрики, кросс-валидация и анализ ошибок.

## Запуск

Откройте блокноты в Jupyter Notebook/JupyterLab или Google Colab. Основные примеры используют Python 3 и `scikit-learn`.

```bash
python -m pip install scikit-learn matplotlib
```

Для дополнительного эксперимента с готовыми эмбеддингами во втором дне:

```bash
python -m pip install sentence-transformers
```

Этот дополнительный блок может потребовать загрузки модели из интернета; без доступа к сети его можно пропустить. Остальные задания рассчитаны на работу с небольшим учебным корпусом.

## Методическое замечание

Каждый день структурирован на четыре пары (ориентировочно 4 × 90 минут). В каждой паре предусмотрены объяснение метода, кодовые эксперименты и задания для самостоятельной работы. Маленькие искусственные корпуса нужны для демонстрации алгоритмов и не позволяют делать надёжные выводы о промышленном качестве NLP-моделей.
